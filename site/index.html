02 / The game

Your next world is waiting.

From sunrise builds to deep caves and multiplayer adventures, Horizon brings the familiar sandbox to a Rust-powered client. The desktop launcher helps you install and start playing.

Experimental · WebGPU required

A world beyond the desktop.

Horizon has an experimental browser edition compiled to WebAssembly. In a supported browser, explore single-player worlds and connect to compatible servers—with saves kept in browser storage.

It needs WebGPU and a cross-origin isolated host. The project repository has the current build and hosting instructions.
